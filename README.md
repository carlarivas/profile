# {carlarivas} · Perfil

Sitio personal de Carla Rivas, publicado en GitHub Pages:
https://carlarivas.github.io/profile/

## Estructura

- `index.html`: página principal (Bootstrap 5 desde CDN + `css/style.css`).
- `css/style.css`: estilos propios de la página.
- `js/`: jQuery, Waypoints y `script.js`.
- `img/`: imágenes e iconos SVG.
- `scss/`: fuentes SCSS de la plantilla original (generan `css/main.css`).

## Desarrollo

```bash
npm install
npm run serve   # servidor local con recarga automática
npm run build   # compila scss/ → css/main.css
```
