# {carlarivas} · Perfil

Sitio personal de Carla Rivas, publicado en GitHub Pages:
https://carlarivas.github.io/profile/

## Estructura

- `index.html`: página principal (Bootstrap 5.3 desde CDN).
- `css/style.css`: estilos propios.
- `js/`: jQuery, Waypoints y `script.js` (contador animado y barra de navegación).
- `img/`: foto de perfil, fondos, iconos SVG y favicons.

No necesita compilación: los cambios en estos archivos se publican tal cual.

## Desarrollo local

```bash
npm install
npm run serve   # servidor local con recarga automática
```
